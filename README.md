# Java 任務學習室

一個以 Phaser.js 製作視覺回饋、以原生 HTML/CSS/JavaScript 製作教材流程的 Java 入門互動任務。

## 學習內容

1. 文字輸出：字串、`System.out.println` 與分號。
2. 變數：變數名稱與儲存值的差異。
3. 條件判斷：比較運算子與 `if / else`。

每關依序使用「預測 → 執行 → 解釋 → 遷移」鷹架。答錯可看提示並重試；完成解釋和遷移問題後才解鎖下一關。反思筆記與進度保存在本機瀏覽器的 localStorage，不會送出。

模擬器會依照本關的預設程式與選項回饋輸出，沒有連接完整 Java 編譯器；它用於概念練習，不會編譯任意 Java 程式。

## 認知負荷與多媒體設計

- 分段原則：三個關卡依序解鎖，每個畫面只處理一個 Java 概念。
- 訊號原則：用底色標出待選程式行，並以清楚的步驟標示目前反思階段。
- 一致性原則：移除裝飾性音效、旁支故事和無關資訊；Phaser 動畫只標記執行狀態，主控台文字另外提供可讀輸出。
- 鄰近與整合：程式碼選擇、執行控制和結果放在同一視線區域；文字解釋緊接對應問題。
- 反思支架：首次選擇和執行結果會並列，接著要求學習者解釋原因，再用新的例子練習遷移。
- 可及性：控制項可用鍵盤操作，動畫尊重減少動態偏好，主要資訊不依賴顏色或 Phaser 畫布才能取得。

## 執行

此為靜態網站，Phaser.js 3.90.0 透過 CDN 載入。可直接以瀏覽器開啟 `index.html`；若瀏覽器限制本機資源，請以靜態 HTTP 伺服器提供此目錄。

靜態部署目錄為 `dist/`。執行 `bash scripts/build.sh` 會將入口、樣式與程式複製到該目錄。
